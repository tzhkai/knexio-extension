# Knexio 阅读伴侣

浏览器插件，右键翻译 + AI 摘要。安装即用，不偷数据。

## 用法

1. 网页中选中文本 → 右键 → **Knexio 阅读伴侣** → 「翻译选中文本」或「AI 摘要选中文本」
2. 点击扩展栏图标 → 弹窗输入/粘贴文本 → 中英日韩互译
3. 点击扩展栏图标 → 摘要标签 → 「摘要页面」→ 一键提取整页核心要点

## 特点

- 内置 AI 程序，安装即可用，无需任何配置
- 翻译无限免费（Google Translate）
- 摘要每天 10 次本地智能提取
- 可自行配置 DeepSeek API Key 解锁更强 AI
- 所有文本本地处理，不经过任何服务器

## 安装

1. 下载本仓库
2. Chrome → `chrome://extensions` → 开启开发者模式
3. 「加载已解压的扩展程序」→ 选择 `knexio-extension` 文件夹
