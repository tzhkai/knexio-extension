# Knexio 阅读伴侣 v1.11.0 更新说明

## 本版本更新内容（商店提交用）

### 中文版

**v1.11.0 更新内容：**

- 🌏 国际化支持：新增中/英文自适应，根据浏览器语言自动切换界面语言
- 📋 侧边栏模式：新增 sidePanel 支持，可在侧边栏中使用扩展功能
- 🌐 修复权限问题：新增 `<all_urls>` host 权限，解决部分网站（如 GitHub Docs）无法提取内容的问题
- 🏷️ 品牌文案国际化：knexio 品牌文案（100+免费工具等）现支持中英文切换
- 🐛 修复：翻译超时提示、内容截断提示现使用国际化文案，不再硬编码中文

---

### English Version

**What's new in v1.11.0:**

- 🌏 i18n support: auto-detect browser language (Chinese/English UI)
- 📋 Side panel mode: new sidePanel support, use the extension in Chrome's side panel
- 🌐 Fix host permission: added `<all_urls>` to fix "Cannot access contents of url" error on sites like GitHub Docs
- 🏷️ Brand copy i18n: knexio brand copy ("100+ free tools" etc.) now supports zh/en
- 🐛 Fix: translation timeout and content truncated messages now use i18n instead of hardcoded Chinese
